ATU-EVENTS waa Event Management System loogu talagalay in lagu maamulo events-ka jaamacadda/dugsiga. System-kan wuxuu isku daraa mobile app, web dashboard, iyo backend API si loo fududeeyo maamulka events-ka ardayda, macallimiinta, iyo admins-ka.

🧱 Technologies Used
📱 Flutter – Mobile Application (Android & iOS)
⚙️ FastAPI (Python) – Backend REST API
🎨 Tailwind CSS – Web Admin Dashboard UI
🗄️ Database – PostgreSQL / MySQL
🔐 JWT Authentication – Secure login system

#👥 User Roles
🧑‍💼 Admin
Create & manage users
Create public & private events
Manage all classes
Full system control

👨‍🏫 Teacher
Create class-specific events only
View assigned classes
Manage student-related activities

🎓 Student
View events (public & class)
Join events
Receive notifications

🚀 Key Features
📅 Event creation (Public & Class-based)
🔔 Real-time notifications
👤 Role-based access control
📊 Class & student management
📱 Mobile-first Flutter UI
🖥️ Admin dashboard with Tailwind CSS
🔐 Secure authentication system
⚡ Fast API performance with FastAPI
🔄 System Workflow
Admin/Teacher creates event via web dashboard or API
FastAPI stores event in database
Flutter app fetches and displays events
Students receive updates & notifications
